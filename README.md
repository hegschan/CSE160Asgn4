# CSE160Asgn4 [Lighting Ball Arcade]

Pac themed arena demonstrating the basic of ambient, diffuse, and specular lighting that shines to the objects. Animal from Blocky animal has also visited Lighting Ball Arcade. Sphere centered to demonstrate the continuous changes from the lighting in different directions and dynamics. 

User interface is implemented within the page that shows the different functions. Point light moves around the environment overtime along with the slider capable of navigating the light. 

Spotlight is also implemented as there are buttons to visualize the normals with each color of the OBJ.
